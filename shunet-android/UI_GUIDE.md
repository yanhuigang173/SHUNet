# SHUNet Android 界面规范

## 布局

顺序：紧凑页头 → 连接概览与操作 → 可展开账号 → 可展开 SHU 常用网址 → 可展开记录 → 版本。

连接与日常操作集中于首屏。账号已填写时默认收起；首次使用和未填密码时展开。记录默认收起。展开状态在屏幕旋转后保留，密码显隐不保留。

常用网址默认收起，摘要显示数量。卡片标题区域控制展开，右上角加号独立用于添加。展开后，每行左侧为打开入口与名称、域名，右侧 48 dp 菜单管理编辑和删除；删除前确认。没有入口时显示添加提示。仅展开时创建网址行视图，不获取网页或远程图标。

## 状态反馈

- 标题、颜色与图标反映最近确认的连接结果；网络查询进度独立展示。
- 查询过程显示阶段文案和不定进度条，不生成虚假的百分比。
- 保存账号时，进度与提示显示在账号区域，不把保存进度展示成校园网认证状态。
- 长状态说明显示摘要，点击可查看全文。操作记录展开后可查看最近 10 条，支持文字选择。

## 输入与可访问性

密码默认隐藏，显隐放在输入框末尾。收起账号或离开应用后重新隐藏。输入内容不写入 Activity 的状态快照。

账号设置中的运营商选择器沿用输入框背景和圆角，右侧使用向下箭头；点击打开原生单选列表。默认校园网，支持中国电信、中国联通、中国移动。选择立即保存，当前项同时展示在收起后的摘要中。选择器下方提示“下次认证时生效”，不把配置选择当作当前在线会话的运营商状态。网络操作或保存期间禁用选择器，防止本次提交与用户所见选择不同。

网址编辑使用原生对话框与同款输入框。保存校验失败时保留输入，在表单内提示原因；键盘“完成”也可提交。旋转时恢复未保存的名称、地址与新增 / 编辑模式。网址配置与认证任务独立，认证或查询期间仍可使用网址功能。

所有只有图标的按钮均提供中文内容描述与长按提示，图标使用代码绘制的原生矢量形状，不依赖字符字体。禁用控件通过降低透明度显示。按钮按实际文字宽度布局，不强制缩小系统字体。
