SHUNet · 校园网工具 v{VERSION}

【开始使用】
左键单击任务栏通知区域里的 Wi-Fi 图标立即查询一次，右键打开菜单；键盘选中图标后按 Enter / 空格也可打开菜单。若找不到，请展开“显示隐藏的图标”。本软件没有常驻主窗口，菜单关闭后继续在后台运行。
首次使用：设置 → 账号与密码，填写校园网账号密码；需要下次保留密码时勾选保存。随后连接 shu 校园 Wi-Fi，点击“一键认证”。

【定时电源】
校园网工具 → 定时电源，打开独立配置窗口。选择关机、重启、睡眠、休眠或唤醒，设置倒计时（2 分钟～7 天），或指定日期、时间。指定时间支持仅一次、每天、工作日（周一至周五）；首次执行需提前至少 90 秒。
点击创建后交由 Windows 保存。关闭窗口或退出 SHUNet 不会取消任务，需保持当前用户登录，锁屏可以。默认仅接通电源时执行，可勾选电池供电也执行。
电源操作前约 60 秒弹出倒计时窗口，可取消本次，关闭该窗口也会取消本次。配置窗口可取消整个计划、移除记录、刷新及核对 Windows 任务；最近执行结果自动更新。
错过的关机、重启、睡眠、休眠不会在下次开机后补执行。不强制关闭应用，未保存工作可能阻止关机／重启。定时开机采用睡眠／休眠唤醒，取决于设备和唤醒计时器策略；完全关机后开机需在 BIOS/UEFI 中配置 RTC，不属于软件可直接实现的功能。点击“能力与说明”查看本机能力和限制。

【菜单主题】
设置 → 菜单主题：默认恢复原先的浅色及宽松行距；经典保留紧凑的系统菜单；现代提供白底、淡蓝信息区和蓝色悬停。主菜单及各级子菜单使用同一主题，独立工具窗口保持原样。
选择保存后，下次打开菜单生效，重启也保留。旧配置自动采用默认。切换不影响认证、在线时长或网络设置，已展开菜单不会临时换肤或重新排版。

【菜单与网络】
菜单展开时固定文字区域宽度，只刷新变化的行，较长内容显示省略号；时长仍按秒更新。鼠标指向子菜单入口或子菜单展开时，父菜单功能按钮暂缓变化，返回主菜单后同步，避免影响当前选择。
主菜单打开时，顶部四行状态与在线时长实时更新；“正在处理…”和认证、下线、自动重连、代理状态也会随任务进度更新，不必关闭重开。仅更新已有本机状态，复用托盘每秒定时器，不额外发起网络检测。
校园认证连接兼容当前校园引导设备的 HTTP/1.1 请求头格式，继续通过物理 Wi-Fi 地址直连门户。手机共享、VPN/TUN 的上网状态不作为校园网认证依据；只有门户确认当前 Wi-Fi 会话后才显示在线。已在手机 USB 共享与 TUN 并存环境中验证，不修改 VPN 和系统路由。认证接口接受请求后可能需要短暂同步，期间显示待确认，不立即认定在线。
• 一键认证：先只读确认是否在线，已经认证则跳过登录并提示；明确未认证才提交，再确认结果。
• 校园网下线：在主菜单点击即可下线认证，保留 Wi-Fi 连接，并保存该网络的自动认证暂停状态；重启仍保留，点“一键认证”或设置里的恢复自动策略可解除。
• 自动重连：勾选后检测校园网异常下线并在后台尝试恢复；默认关闭。网络暂时不可达时会等待重试；密码错误、验证码等问题需要手动处理。
• 系统代理：开关位于主菜单，显示当前已开启 / 已关闭，点击切换。地址请在“设置 → Windows 设置 → 代理”中配置；需要先运行代理软件。
• Wi-Fi 网络：启动先显示系统已有网络，再异步扫描一次；展开子菜单时读取最新列表，显示网络、信号及校园网标记。扫描超时或失败时保留可用列表并标为缓存，具体原因见运行记录。点击“刷新附近 Wi-Fi”重试；没有系统数据时仍显示已知当前连接，并提供 Windows Wi-Fi 设置和位置权限入口。首次需要 Wi-Fi 密码时会转到 Windows 设置。名称含 shu / CMCC 的网络均会尝试检测已适配的校园门户；名称本身不表示已经认证，只有门户确认后才显示在线。
• 校园网工具：打开认证网页、立即查询一次，或执行代理 / 直连测速、取消、查看 / 复制测速结果。
• 运行状态与记录：展开原生子菜单，直接查看状态详情、今日重连统计和最近六条运行记录（新记录在上）。点击“查看详细信息…”打开独立窗口，按日期或仅自动重连筛选三天日志、分页、复制状态和全部筛选记录。主菜单顶部恢复四行原生文字，不显示重连次数或检测倒计时。
• 今日自动重连：按北京时间统计曾在线后实际发出的自动重连认证请求，以及已确认恢复次数；首次自动认证、手动登录和查询不计入。未确认包含失败和结果未知，次数不能代替当前在线状态。新版开始记录，旧版历史无法补算。
• 日志保存：本机 %APPDATA%\CampusLinkTray\runtime-logs 保留最近 72 小时，启动及每小时自动清理过期记录；重启保留，写入前隐藏账号密码。可在状态窗口打开日志目录。
• ShuWlan-1X：在 Windows Wi-Fi 处输入账号密码完成 802.1X 连接，不需要网页认证。软件不检测此网络的门户，不向网页提交账号密码；即使强制设为校园网模式也保持此规则。

【常用网址】
“SHU 大常用网址”预置 9 个入口，迎新系统已更新为提供的 newsso 单点登录地址。点击用默认浏览器打开；可新增、编辑和删除，自动保存，重启后保留。省略协议时补 https://，最多 64 个。

【全局快捷键】
默认一键认证使用 Ctrl+Shift+U，立即查询一次使用 Ctrl+Shift+S，其他功能均未设置。软件在托盘运行时可从其他程序中使用。升级时保留自定义组合键及全部清空的设置，Ctrl+Shift+S 已被其他功能使用时不覆盖。
在“设置 → 快捷键”选择功能，再点击右侧输入框直接按组合键，最后点击保存。支持认证、下线、代理开关、重连/自动认证开关、刷新 Wi-Fi、断开 Wi-Fi、重新检测、认证页、托盘菜单、账号设置、帮助、Windows 网络设置、配置目录、导入/导出、新增网址、复制信息，以及两种测速、取消测速、查看 / 复制测速结果等 27 项。新增测速功能默认没有快捷键。
“清除当前”或输入框中的 Backspace 可取消所选功能的快捷键；“恢复默认”恢复 Ctrl+Shift+U 一键认证与 Ctrl+Shift+S 立即查询一次，其余清空。修改后需点击保存，取消不会保存。可以清除全部快捷键；保存后重启仍保留清除结果。
快捷键支持字母、数字、功能键和导航键，修饰键可用 Ctrl / Alt / Shift / Win。除功能键外，至少搭配 Ctrl、Alt 或 Win；F12 由 Windows 保留，部分 Win 组合键也可能无法注册。重复或被其他程序占用时会提示，无法保存此组合；启动或导入时的占用也会提示，可重新打开快捷键设置修改。菜单右侧显示当前已生效的快捷键。
编辑期间暂停本软件的全局快捷键响应；菜单或设置窗口打开时不触发快捷操作。网络忙碌时认证等操作等待当前任务完成后再按。按住组合键不会连续提交操作。
快捷键自动存入默认配置，包含在导出 / 导入中，重启后恢复；从桌面版导入账号时保留现有快捷键。

【一键测速】
在“校园网工具”选择“一键测速（通过代理）”或“一键测速（直连）”。结果包含 HTTP 延迟、下载 / 上传 Mbps、载荷流量和耗时；同一测速服务为 Cloudflare。测速只在主动点击后运行，一次一个任务，关闭状态检测也可使用。
代理测速读取 Windows 保存的手动代理地址，不要求打开系统代理开关；没有保存地址时使用软件配置的 proxy_server。支持统一地址或 https= 分协议地址，支持 HTTP / HTTPS / SOCKS5 / SOCKS5h。请先运行代理软件；代理错误不会退回直连。不执行 PAC，代理软件的分流仍由其规则决定。
直连测速跳过手动 HTTP 代理和环境变量 HTTP 代理，仍受 TUN、VPN、USB 共享和系统路由影响，不强制绑定校园 Wi-Fi，也不绕过 TUN。
两种模式均不改变 Windows 代理开关，不提交校园账号密码。测速服务失败不会被认定为校园网下线，也不会改变托盘认证颜色。
测速时打开卡片式原生窗口：延迟、下载、上传分别以大号数字显示，单位与数值分开；细进度条和当前阶段显示进度。进行中的速率明确标为“阶段均值”，失败阶段不显示为有效速度。上传请求尚未结束时也能观察进度。
顶部可切换直连 / 代理测速；下方保留两种模式最近一次的时间、速度和完成状态，方便对比。进行中可取消，结束后可打开“详细结果”查看完整记录或复制结果。窗口随 DPI 缩放并限制在显示器工作区；空间不足时收起辅助说明和对比区，完整内容仍可查看或复制。关闭窗口可以继续后台测速；完成时托盘通知提示，点击通知或从“校园网工具 → 查看测速进度与结果”重新打开。窗口打开时直接展示完成结果，不再重复弹窗；完成后停止窗口的周期刷新。
结果只保存在内存，退出后清空。失败或取消时保留已完成阶段，其他显示“未完成”，说明具体原因。HTTP 延迟是预热后五次往返的中位数，与 Ping 不同；载荷速度不等于宽带套餐速率。
下载 / 上传各以约 8 秒为目标，最多传输 32 MiB / 8 MiB 载荷，另计协议开销。单次请求最多 8 秒，整体按 45 秒截止时间限制后续请求；取消后不再发起新请求，等待当前有超时限制的请求返回。网络变化、睡眠或认证 / 下线等操作会取消测速。
测速使用按需临时线程和流式读写，任务结束后释放，不影响后台校园网状态检测。

【自动与启动】
在“设置 → 自动与启动”里启用“连接校园 Wi-Fi 后自动认证”和“开机启动”。开机启动默认关闭，对当前 Windows 用户生效，不需要管理员权限。请先把 exe 放在固定位置；移动或更换新版后，点击“更新到当前副本”更新启动路径。

【启动和切换网络】
启动先只读确认：校园网已认证则直接使用，不重复提交账号密码；同时结束本次首次认证机会。自动认证仅用于进入校园网络后的首次登录；自动重连仅恢复本次已经在线、随后意外下线的会话。关闭自动重连时，首次自动认证不会代替它反复恢复掉线。首次登录遇到临时请求错误最多三次尝试，仍需每次先确认未认证；明确拒绝、密码问题或请求已经接受后不反复首登。
切换网络、同一网络更新 IP 或睡眠恢复时先等待连接稳定，再检查。代理开关、刷新 Wi-Fi、保存设置不清除已完成首次认证的记录。短暂断线后仍记住本次曾在线；真正切到另一个 Wi-Fi 才开始新的连接会话。
普通网络停止定期校园门户请求，不自动提交账号；校园认证与下线菜单不可用。只连接 USB 共享或有线接口时显示其他接口已连接，不把 Wi-Fi 未连接等同于全机没网络。接口存在不代表互联网一定可用。
“设置 → 当前 Wi-Fi 类型”可选自动识别、校园网络、普通网络，按网络名保存。默认以 shu / CMCC（排除含 1x）作为候选；普通 CMCC 热点可手动设为普通，其他名字的校园 Wi-Fi 可设为校园。标记校园仍须通过实际门户和物理 Wi-Fi 地址核对才能认证。
手动下线暂停写入配置，切走再切回、重启均保留；可手动一键认证恢复，或解除暂停后按原自动开关处理。校园网和 USB 同时连接时，校园查询只走校园 Wi-Fi，不用 USB 或代理的连通性推断校园已经认证。
门户超时、未知响应、外部测速失败不会被当作认证下线。门户持续同步时逐步降低检测频率，不反复提交密码。账号、密码、欠费、验证码等问题需更新凭据或手动认证处理，只读重新检测不会解除保护。
若认证状态提示网卡地址不一致：软件支持 SHU 门户的编码 wlanuserip 参数；真实明文地址冲突或无法识别的参数仍会暂停认证，防止在连接变化时误提交。手动“一键认证”会重新创建检测会话并确认当前网络。

【运营商选择】
在“设置 → 运营商”选择校园网、中国电信、中国联通或中国移动，默认校园网。选择自动保存，重启、配置导入导出保留；旧配置默认校园网，从桌面版重新导入账号时保留当前选择。手动认证、自动认证和自动重连使用同一选择，不改变账号，不自动切换为其他运营商。当前已在线会话不会因切换选项而下线，新选择在下次认证时生效。账号没有开通所选运营商时，门户可能返回未绑定或未开通提示，这是正常权限结果；保留原因及选择，已识别的权限问题暂停自动重复提交，更正账号或运营商后可重新认证。

【状态检测与档位】
Wi-Fi 名称改用只读取 SSID 的 GetConnectedSsid 接口，并按物理网卡匹配，不再使用读取 BSSID 的旧连接查询接口。定期检测保留名称缓存；连接变化、睡眠恢复、手动立即查询会重新读取；认证和下线前仍实时核对。正常监听时每 10 分钟重新确认一次名称，监听不可用时每 60 秒重新确认。附近网络扫描保持原样，启动及手动刷新扫描仍可能出现 Windows 位置提示。
在“设置 → 状态检测”里勾选“启用状态检测”开启，取消勾选关闭；可以选择自适应、极高、高、中、低五种模式，名称后标注间隔秒数，自动保存到配置并随导入导出保留。缺少档位的旧配置默认中档。检测关闭时仍能选择档位，重新开启后生效。
稳定在线时极高档每 3 秒查询，高档 10 秒，中档 30 秒，低档 120 秒；疑似下线分别在 2 / 2 / 3 / 5 秒后复查。所有模式采用同一套认证判定，单次超时为查询异常，明确未认证须复查后才允许自动恢复。包括极高档在内，查询异常仍逐步延长重试间隔；档位主要改变更新及时性和请求次数。
自适应刚确认在线时每 10 秒检查，连续 3 次正常后改为 30 秒，持续稳定超过 5 分钟后改为 60 秒。最近 10 分钟内两次明确意外下线时，恢复后加强观察 5 分钟，每 10 秒检查。手动下线与查询超时不计入意外下线；更换 Wi-Fi 清除该会话的稳定统计。
切换档位不重置手动下线暂停、账号错误保护、首次登录机会或重连冷却。运行状态与记录显示模式、本轮间隔、下次查询预计时间和调度原因；时间以打开菜单时为准。间隔从查询结束后计算，实际执行可能受网络超时及其他任务影响。
网络变化通知会先核对当前 Wi-Fi 的 SSID、网卡索引和 IP，相同连接身份的通知不重置查询进度。每 60 秒有一次本机信息读取作为事件遗漏的后备，不访问门户。
关闭后停止定期门户查询，释放检测客户端，暂停自动认证与自动重连；原来的两个自动开关偏好仍保留，菜单标注“已暂停”。再次开启后重新检测当前连接，再恢复允许的自动操作。
校园网络关闭检测时显示蓝色“状态检测已关闭 · 认证状态未知”，不沿用旧的绿 / 红状态。普通网络和其他活动接口保持蓝色；没有发现连接接口时显示灰色。最近检测 / 上次确认在线时间仅作历史记录。
仍可使用一键认证、校园网下线、系统代理和刷新 Wi-Fi。菜单“立即查询一次”、左键单击托盘图标或查询快捷键共用只读检测，不提交账号密码，不开启已关闭的定期检测；手动认证被门户接受后补做一次只读确认，不自动重试或重连。结果在“运行状态与记录”查看，定期检测保持关闭。普通网络只刷新本机连接信息，不访问校园门户。连续点击或按键在 1 秒内合并，后台不堆积查询；认证等任务忙碌期间合并排队，已有任务结束后处理。有效请求立即显示约 700 毫秒刷新标记，排队或查询未结束时继续显示；悬浮提示区分等待处理和查询中，运行记录显示手动查询的接收及处理结果。菜单或设置窗口打开时不响应图标查询。
关闭时取消旧任务的后续步骤；已经发出的请求需等待有超时限制的返回，不能撤回。Windows 网络变化通知仍用于更新本机 Wi-Fi 信息，不触发门户请求。

【配置文件】
默认配置路径：
{CONFIG_PATH}
为兼容旧版，配置继续使用 CampusLinkTray 目录；升级命名不会丢失账号、偏好和收藏。
可在“设置 → 配置文件”里打开目录、复制完整路径，或选择 JSON 文件导入 / 导出。
• 导出包含账号、记住的加密密码、自动认证/重连/状态检测开关与档位偏好、各网络类型与暂停标记、代理地址、收藏网址和快捷键。未勾选记住的密码不会导出。密码使用 Windows DPAPI 加密，仅可由原电脑的同一 Windows 用户恢复；请妥善保管备份。
• 从文件导入会替换上述软件配置。导入前完整检查文件，失败保留原设置；成功前将旧文件备份为同目录的 settings.before-import.json，可再次导入此文件恢复。
• “从桌面版导入账号配置”沿用旧版账号等配置，保留托盘版的收藏网址、快捷键、自动重连、状态检测开关与档位和各网络类型与暂停选择。
• 导入不会更改 Windows 开机启动注册项，也不会立即切换系统代理。
• 可以退出程序后手动修改 JSON；运行中手动修改不会立即生效。

【图标状态】
灰：未发现已连接 Wi-Fi 和其他具有有效地址的活动接口。
蓝：普通网络 / 其他接口已连接、状态检测关闭，或校园认证尚未确认、等待地址、手动下线等。
绿勾：通过本机校园 Wi-Fi 的门户接口确认认证在线。
橙：正在认证、确认认证结果或执行校园网下线。
红：两次确认已在线会话下线、认证返回失败，或已识别的校园门户连续三次检测异常；检测异常表示状态未知，不等于已经断网。
同色圆点加载：正在只读查询状态。灰、蓝、绿、橙、红各有一个查询版本，沿用查询前的颜色，不因点击查询就把已认证改为待确认。查询结束后按返回结果恢复图标；Wi-Fi / IP 实际变化时立即使旧颜色失效，真实认证或下线操作优先显示操作状态。
左键单击、查询快捷键或菜单查询至少短暂显示约 0.45 秒反馈，快速完成也能看见；结果处理不被延迟。后台定期查询不强制延长显示。查询时菜单和悬浮提示会写明“正在查询”及查询前的状态，查询标记不是新的认证结论。
图标与菜单使用同一个认证状态，代理或自动重连开关不代表是否已认证。单次超时不认定掉线、不触发重复提交。状态检测开启时，即使自动认证和重连均关闭也会只读更新；浏览器登录后的状态在所选档位的下一次检测更新，也可从设置或校园网工具手动查询。手动下线只暂停自动提交，不改变状态检测的选择。

【IP 信息与设备列表】
校园网工具 → IP 信息与出口查询：查看并逐项复制内网 IPv4、本机 IPv6、网关、DNS、直连/代理公网 IP 和国家/地区，也可复制全部。下拉框选择本地接口，公网结果是当前系统出口，与该选择独立。直连跳过 HTTP/SOCKS 代理，TUN/VPN 仍可能接管；代理软件也可能按规则直出。代理失败不会回退为直连。公网查询来源 ipwho.is，仅打开或手动刷新窗口时请求。
校园网工具 → 局域网与共享设备：默认筛选热点 / USB 共享设备，USB/RNDIS 接口会单独标记；也可切换具体接口或查看全部接口。支持复制所选 IP 和全部记录。电脑通过 USB 给开发板共享网络时，在这里查看开发板已发现的地址；“IP 信息”窗口的本地接口 IP 属于电脑。未连接开发板时可保持空列表，连接并通信后点击刷新。缓存不等于完整 DHCP 租约表，“缓存，在线待确认”不承诺设备仍在线。设备尚未通信、休眠或 Windows 接口权限受限时可能无法完整显示。不扫描整个子网，不修改共享设置。
手机给电脑 USB 共享上网时，手机负责分配地址，电脑无法列出手机的其他客户端。电脑给其他设备共享网络时，选择相应的共享下游接口查看已发现 IP。关闭查询窗口不会退出托盘、断网或执行校园网下线。

【常见问题】
看不到网络：刷新附近 Wi-Fi，检查 Windows Wi-Fi 与位置权限。
无法认证：先检查账号密码和当前 Wi-Fi，再从校园网工具打开认证网页；网页需要验证码等操作时请在浏览器完成。
重复运行：程序有单实例限制。更新时先从旧版菜单退出，再运行新版。请避免桌面版和托盘版同时进行自动认证。
退出软件不会执行校园网下线，也不会自动关闭系统代理。
