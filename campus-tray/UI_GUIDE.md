# SHUNet 子窗口界面规范

已用于 v0.7.0 的原生测速、网址编辑、快捷键设置、帮助与详细结果窗口。实现入口为 `src/ui.rs`，资源模板只负责控件与键盘顺序，布局由同一套逻辑像素规则计算。

## 视觉语言

浅灰画布、白色卡片、深色文字、蓝色主要操作。保留 Windows 标题栏、关闭按钮、输入控件与键盘操作；窗口内以信息层次和留白替代旧式 GroupBox 与大块文本框。

| 角色 | 数值 |
| --- | --- |
| 画布 | `#F5F7FB` |
| 卡片 / 页头 / 操作栏 | `#FFFFFF` |
| 正文 | `#192B44` |
| 辅助文字 | `#60718A` |
| 边框 | `#DFE6F0` |
| 主按钮 / 下载数值 | `#2563EB` |
| 上传数值 | `#098E7B` |
| 完成 | `#168B5D`，浅绿底 `#E8F7EF` |
| 进行中 | 蓝色，浅蓝底 `#EAF1FF` |
| 未完成 / 失败 | `#A66B0D`，浅黄底 `#FFF6E0`，同时显示文字原因 |

- 正文字体 Microsoft YaHei UI：13 DIP，辅助文字 12 DIP，标题 22 DIP / 600。
- 测速数字 Segoe UI：32 DIP / 600。数值与单位分层，避免单位挤占数字空间。
- 页面左右边距 24 DIP，卡片间距 12 DIP，卡片内边距 16 DIP。
- 卡片圆角 12 DIP、按钮圆角 7 DIP、输入框圆角 8 DIP；边框 1 个物理像素。
- 按钮高度 34 DIP；主要操作蓝底白字；次要操作白底描边；取消进行中的测速使用浅红色。
- 交互提供悬停、按下、不可用、焦点状态，列表选中使用浅蓝底。

## 四种窗口

### 网络测速 · 720 × 520 DIP 客户区

1. 页头：应用图标、标题、说明，右侧直连 / 代理模式按钮与状态胶囊。
2. 当前路由说明：保留直连与 TUN / VPN 的实际关系，代理地址由后端清除凭据信息后展示。
3. 三张结果卡：HTTP 延迟、下载、上传；进行中明确标为阶段均值，失败阶段保留“未完成”。
4. 阶段文字与百分比、6 DIP 细进度条；阶段错误可在详细结果查看全文。
5. 最近对比：直连 / 代理各一行，下载 / 上传速率、完成时间与状态；没有记录时使用占位符。
6. 底栏：进行中可取消并转入后台；结束后提供详细结果、复制与完成。

高度不足 500 DIP 时压缩间距；不足 470 DIP 时收起最近对比区，仍可通过详细结果 / 复制读取两种模式的记录；不足 370 DIP 时进一步收起路由说明并压缩头尾。运行中最多每 400 ms 刷新一次，完成即停止。

### 常用网址 · 520 × 332 DIP 客户区

名称与 URL 两个完整宽度输入区，聚焦时蓝色描边；下方保留协议说明，底部取消 / 保存。沿用地址验证、重复检查与输入长度限制。

### 全局快捷键 · 720 × 548 DIP 客户区

左侧功能列表、右侧当前功能与组合键录入；快捷键右对齐，未设置项用辅助色。录入方式、恢复默认、保存前验证与冲突提示保持原逻辑。长列表滚动显示。

### 帮助 / 详细结果 · 720 × 548 DIP 客户区

标题与说明、白色阅读卡片、可选择和滚动的原生文本区，底栏复制全文 / 关闭。详细结果复用阅读窗口，避免测速页出现两个大文本框。

## DPI、键盘与资源

- 清单启用 Per-Monitor V2；跨显示器收到 `WM_DPICHANGED` 后重新计算布局与字体，按显示器工作区限制外部窗口大小。使用固定 DIP 布局，禁用对话框的二次自动布局。标题栏与圆角由 Windows 提供，支持的系统上设置 DWM 标题栏颜色。
- 保留 Tab / Shift+Tab、Enter、Escape、列表方向键与原生复制选择；自绘按钮与列表显示键盘焦点，不使用鼠标钩子替代原生控件。
- 主题资源在打开窗口时创建，关闭时释放；字体更换完成后再释放旧字体。没有常驻绘制循环、额外 UI 线程或 WebView。
- Windows 凭据窗口与文件选择窗口保持系统样式。该规范为浅色主题；未加入自定义暗色主题。
