# 使用与常见问题

## 选择平台

Windows 提供无需安装的托盘程序。Android 提供原生手动认证工具；当前 APK 是调试签名预览包，不包含自动重连或后台常驻功能。两端独立保存配置，不互相导入加密密码。

## 认证前

先在系统中连接校园 Wi-Fi，再填写校园账号并选择已开通的服务。名称含 SHU / CMCC 只是识别线索，认证是否成功以当前物理 Wi-Fi 的门户会话证据为准。其他网卡、手机共享或代理能够访问互联网，不能证明校园 Wi-Fi 已认证。

“请求已提交”“门户等待同步”和“已确认在线”是不同状态。未知状态时可先刷新；不要反复点击登录。验证码、欠费或服务未开通请打开学校认证网页处理。

## 找不到 Windows 窗口

程序默认只在通知区域运行。展开任务栏隐藏图标，右键 SHUNet 打开菜单。关闭工具窗口后仍在托盘运行，退出请使用托盘菜单。升级先退出旧版本，避免多个版本干预同一会话。

## 自动认证与自动重连

首次自动认证负责连接后的首次未认证登录；自动重连负责本次已确认在线后意外掉线的恢复。两者都要求状态检测开启及可用账号密码。未记住密码时，重新启动后需要输入密码。

手动校园网下线保留 Wi-Fi 并保存暂停意图，不会立刻自动登录回来。“一键认证”或设置中的“恢复当前网络的自动策略”可解除暂停。网络物理断开仍由 Windows 恢复无线连接。

## Android 安装和升级

确认文件来自本仓库 Releases，使用 SHA-256 校验文件完整性。按系统提示允许所用文件来源安装 APK。设备策略不允许安装时按设备管理要求处理。

当前文件名包含 `debug`，使用调试签名。只有包名和签名一致才能直接覆盖升级；不同构建者的调试签名通常不同。更换为正式签名可能需要卸载旧包，卸载会删除已保存的应用数据。项目没有提供可公开分发的签名私钥。

## 系统代理和测速

Windows 代理按钮只切换手动代理配置，代理软件需自行启动。直连测速禁用 HTTP 代理，但仍服从系统路由、VPN / TUN。代理测速失败不会回退直连。测试结果可能因分流和服务出口不同而变化。

## 数据保存

Windows 设置目录为 `%APPDATA%\CampusLinkTray`，日志保留最近 72 小时。不要公开整个配置目录或诊断输出；反馈问题时遮盖账号、密码、Cookie、会话索引和本机网络标识。导出的 DPAPI 密码不能跨电脑 / 用户解密。Android 数据在应用私有目录中，密码密钥由 Keystore 管理。

## 定时电源

已创建计划使用独立 Windows 执行器，退出 SHUNet 后仍然可能执行。需要停用时进入定时电源窗口取消计划；仅删除 EXE 不会取消计划。执行受当前用户登录、设备供电和系统策略限制，界面显示已提交不代表系统已完成电源操作。

## 问题反馈

在 [Issues](https://github.com/yanhuigang173/SHUNet/issues) 中说明平台、系统版本、软件版本、操作步骤、预期与实际结果。校园门户适配问题请给出脱敏错误文字；无需提供真实密码或完整门户跳转查询串。
