SHUNet Android 原生精简版 **v0.4.0**，支持 Android 8.0 / API 26 及以上。

**此附件为调试签名预览包，尚未提供正式签名安装包。** 文件名中的 `debug` 与预发布标记刻意保留。

### 本版变化

- 增加可折叠的 SHU 常用网址，预置 9 个校园入口。
- 支持新增、编辑、删除网址并本机保存。
- 保留账号配置、四类运营商选择、一键认证、校园网下线和只读刷新状态。

下载 `SHUNet-Android-v0.4.0-debug.apk`，使用 `SHA256SUMS-android.txt` 校验文件完整性。先在系统中连接校园 Wi-Fi，再打开应用配置账号和运营商。

没有自动认证、自动重连或常驻后台服务。移动数据可以同时开启，认证请求仍绑定物理 Wi-Fi。

覆盖安装要求包名与签名一致；不同构建环境生成的调试包未必能覆盖此包。将来更换正式签名可能需要卸载旧包，卸载会清除应用数据。仓库不包含任何签名私钥。

未在本次仓库整理中进行 Android 校园 Wi-Fi 实机认证验证；请在自己的设备上核对登录、已在线时重复认证、下线和网络变化行为。
