SHUNet Windows 原生托盘版 **v0.14.3**，适用于 Windows 10 / 11 x64。

### 下载

- `SHUNet-v0.14.3.exe`：直接运行的单文件程序。
- `SHUNet-v0.14.3-windows-x64.zip`：便携包，含程序、内置使用说明副本和许可文件。
- `SHA256SUMS-windows.txt`：下载文件的 SHA-256 校验值。

### 本版变化

- 修复 Windows 暂时拒绝更新图标后刷新角标可能卡住的问题。
- 固定查询反馈计时器，避免普通状态消息反复延长标记。
- 调整重复点击合并间隔，连续查询反馈更及时。

包含校园认证与下线、运营商选择、自动策略、72 小时记录、常用网址、快捷键、系统代理、直连 / 代理测速、IP 与共享设备和定时电源等功能。

升级先退出旧版，再运行新文件。配置继续位于 `%APPDATA%\CampusLinkTray`。程序无常驻主窗口，请在通知区域右键打开菜单。软件没有代码签名证书。

Android 独立维护为 v0.4.0，调试签名预览包见 `android-v0.4.0` 预发布，不与 Windows 版本号同步。

这是当前源码的首次仓库发布，保留原版本号。默认 Rust 测试、构建结果及验证边界见仓库 `docs/VALIDATION.md`；校园 Wi-Fi 实机操作需用户自行核对，不以编译结果代替认证成功。
